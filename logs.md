## Сценарій 1: Успішний розрахунок (12 + 7)

[2026-08-22T16:11:03.201Z] chat=787404174696 step=calc:result status=success :: Обчислено: 12 + 7 = 19

Користувач ввів "12+7", калькулятор розпізнав вираз і порахував результат (крок calc:result,
status=success). У чаті бот показав "✅ Результат: 12 + 7 = 19".

## Сценарій 2: Некоректний ввід (abc)

[2026-08-22T16:12:47.558Z] chat=787404174696 step=calc:validation_error status=error :: Не розпізнано вираз: "abc"

Користувач ввів "abc" замість числового виразу. Функція не знайшла збіг з регуляркою
(крок calc:validation_error, status=error). Бот показав повідомлення "⚠️ Не розпізнав вираз "abc".
Формат: число оператор число, напр. 12 + 7" і не завис.

## Сценарій 3: Збій зовнішнього сервісу (НБУ API)

[2026-08-22T16:15:12.904Z] chat=787404174696 step=nbu:error status=error :: HTTP status undefined

Запит до API НБУ повернув помилку (URL було навмисно зламано / статус-код не 200),
тому Format Currency пішов у гілку помилки (крок nbu:error, status=error).
Користувач побачив "⚠️ Не вдалося отримати курс, спробуйте пізніше." замість технічної помилки чи порожньої відповіді.
